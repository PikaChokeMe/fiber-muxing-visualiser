INSIDE THE EXPERIMENT

A few words about light.

Each message is encoded as UTF-8 and transmitted most-significant bit first. A one turns its wavelength on; a zero turns it off. All channels share a clock, but repeat independently.

No time travel.

Editing restarts future transmission for that channel. Every emitted bit keeps its original wavelength and arrival time. The receiver resets only when the first bit of a new sequence arrives, even if it is zero. Sequence markers are demonstration metadata, not extra light or framing bits.

The character that hasn’t quite arrived.

The faint preview fills the current byte’s missing bits with zeros. It may change from @ to H before H is confirmed. Control bytes have names such as NUL and SPACE. UTF-8 characters wait for all their bytes; hex previews show unfinished non-ASCII bytes.

Measured wavelengths. A screen approximation.

Equal-power monochromatic contributions are summed using the CIE 1931 2° standard observer, then converted from XYZ to linear sRGB. Fixed exposure is 0.62. Negative RGB components are clipped and highlights are scaled together if they exceed the display range. This is a documented display approximation, not an exact reproduction of spectral light. Glow is decorative.

This demo treats 380–780 nm as visible. Outside that range, the optional false-color view substitutes violet for UV and orange for IR. It is explicitly illustrative. Wavelengths are ideal, perfectly separable channels; duplicate wavelengths are flagged and practical filter bandwidth is not modeled.

Time is stretched.

The four-second journey is illustrative, not a real fiber distance. Changing the bit rate affects future launches. Pause freezes the simulation; Step advances one bit interval. Hidden browser tabs pause rather than skipping unseen arrivals. Restart explicitly clears the whole demonstration.

Messages and settings are saved only in this browser. Blank messages emit no bits. Removing a channel stops future launches and lets its remaining bits drain.
